# 캐릭터 그림 넣는 곳

여기에 PNG를 넣으면 코드로 찍는 픽셀 격자 대신 그 그림을 씁니다. 커서, 캐릭터 선택 화면, 좌상단 표시, 결과 화면에 한꺼번에 반영됩니다. 파일이 없으면 코드에 적힌 격자를 그려서 씁니다.

## 파일 이름

| 캐릭터 | 파일 |
|---|---|
| 멍멍이 | `dog.png` |
| 고양이 | `cat.png` |
| 토끼 | `rabbit.png` |
| 햄스터 | `hamster.png` |

이름은 `prototype/index.html`의 `CHARS` 배열에 있는 `key` 값입니다.

## 조건

- **배경은 투명**이어야 합니다. 흰 배경이면 커서에 흰 사각형이 따라다닙니다.
- **정사각형**으로 맞춰 주세요. 네 개가 다른 비율이면 선택 화면에서 크기가 어긋납니다.
- **32×32 이하**를 권합니다. 브라우저는 128px보다 큰 커서 이미지를 무시합니다. 화면에는 크게 보여야 하니, 작게 만들고 확대하는 쪽이 맞습니다. 확대할 때 뭉개지지 않도록 `image-rendering: pixelated`가 이미 걸려 있습니다.
- 크기가 서로 달라도 동작은 하지만, 표시 크기는 코드의 격자 크기(20×20)를 기준으로 계산됩니다. 다른 크기를 쓰시면 `charEl()`의 계산을 그 크기로 바꿔야 합니다.

## 커서 기준점

커서의 클릭 지점은 지금 그림의 `(8, 2)` 픽셀입니다. 캐릭터 머리 왼쪽 위쯤입니다. 그림에 맞게 옮기려면 `setCursor()`의 `8 2`를 고치면 됩니다.
