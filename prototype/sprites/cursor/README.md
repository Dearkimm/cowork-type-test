# 커서

`hand.png` — 버튼 위에 뜨는 손가락 커서입니다. 40×44, 손끝 기준점은 (10, 1)입니다.

직접 그렸습니다. 게임에서 뽑은 커서 파일을 그대로 쓰면 저작권에 걸립니다.

## 어떻게 그렸나

격자를 한 칸씩 손으로 찍지 않고 **도형으로 채운 뒤 테두리를 둘렀습니다.** 검지는 캡슐, 접힌 마디도 캡슐, 주먹은 모서리를 크게 굴린 사각형입니다. 이 크기에서 둥근 맛은 손으로 찍어서는 잘 안 나옵니다.

`hand.py`가 그 스크립트입니다. 숫자만 바꾸면 다시 뽑힙니다.

여기까지 오면서 걸렸던 것들입니다.

- **검지를 얇고 길게 하면 빼빼로가 됩니다.** 짧고 굵어야 만화 손으로 읽힙니다.
- **소매를 사각형으로 얹으면 둥근 바닥이 잘려 네모가 됩니다.** 주먹 아랫부분을 잘라서 색만 바꿔야 합니다.
- **손가락 사이 골을 전부 파면 손이 검게 뒤덮입니다.** 검지 오른쪽과 첫 마디 옆만 짧게 팝니다.
- **주먹 왼쪽을 너무 안으로 넣으면 검지와 붙어 벙어리장갑이 됩니다.**
- 기울기는 검지 캡슐의 위아래 좌표를 다르게 줘서 만듭니다. 격자로 한 칸씩 옮기면 꺾인 것처럼 보입니다.

## 색

| 쓰임 | 색 |
|---|---|
| 테두리 | `#2E3A5C` |
| 손 | `#FFFFFF` |
| 그늘 | `#CBDDF5` |
| 소매 | `#5D9EE4` / `#3574BC` |

## 바꿀 때

- **배경은 투명**이어야 합니다.
- **128px을 넘으면 브라우저가 커서를 무시합니다.** 지금 44px이라 여유가 있습니다.
- 기준점(`index.html`의 `--hand` 뒤 두 숫자)은 **손끝 픽셀의 좌표**입니다. 그림을 고치면 같이 맞춰야 실제로 가리키는 지점이 맞습니다.
