# 커서

`hand.png` — 버튼 위에 뜨는 손가락 커서입니다. 30×40, 손끝 기준점은 (7, 1)입니다.

직접 그렸습니다. 게임에서 뽑은 커서 파일을 그대로 쓰면 저작권에 걸립니다. 검지는 곧게 펴서 주먹 위로 충분히 솟게 하고, 접힌 마디를 바짝 붙였습니다. 검지가 짧으면 그냥 쥔 주먹으로 읽힙니다. 검지를 중간에 꺾었더니 누가 잡고 구부린 것처럼 보였고, 옆이 비어 있어서 다른 손가락으로 읽혔습니다. 주먹 모서리는 굴렸고 흰 손에 파란 소매를 달았습니다.

색은 `--edge-deep` 계열 남색 `#2E3A5C`, 흰색, 그늘 `#C9DCF5`, 소매 `#5D9EE4` 넷입니다.

바꾸실 때 조건입니다.

- **배경은 투명**이어야 합니다.
- **128px을 넘으면 브라우저가 무시합니다.** 32~48px 안쪽이 안전합니다.
- 기준점(`index.html`의 `--hand` 뒤 두 숫자)이 실제로 가리키는 지점과 맞아야 합니다. 손끝 픽셀의 좌표입니다.
