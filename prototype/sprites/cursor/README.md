# 커서

`hand.png` — 버튼 위에 뜨는 손가락 커서입니다. 30×36, 손끝 기준점은 (9, 1)입니다.

직접 그렸습니다. 게임에서 뽑은 커서 파일을 그대로 쓰면 저작권에 걸립니다. 검지를 왼쪽으로 눕히고 주먹 모서리를 굴렸으며, 흰 손에 파란 소매를 달았습니다.

색은 `--edge-deep` 계열 남색 `#2E3A5C`, 흰색, 그늘 `#C9DCF5`, 소매 `#5D9EE4` 넷입니다.

바꾸실 때 조건입니다.

- **배경은 투명**이어야 합니다.
- **128px을 넘으면 브라우저가 무시합니다.** 32~48px 안쪽이 안전합니다.
- 기준점(`index.html`의 `--hand` 뒤 두 숫자)이 실제로 가리키는 지점과 맞아야 합니다. 손끝 픽셀의 좌표입니다.
