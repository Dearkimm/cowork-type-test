# 커서

`hand.png` — 버튼 위에 뜨는 손가락 커서입니다. 36×44, 손끝 기준점은 (8, 1)입니다.

직접 그렸습니다. 게임에서 뽑은 커서 파일을 그대로 쓰면 저작권에 걸립니다. 검지는 세 칸마다 한 칸씩 옮겨 왼쪽으로 눕혔습니다. 한 번에 꺾으면 손가락이 부러진 것처럼 보여서, 여러 번 나눠야 기울기로 읽힙니다.

그 밖에 형태에서 걸렸던 것들입니다.

- 검지가 짧으면 그냥 쥔 주먹으로 읽힙니다. 주먹 위로 열 칸쯤 솟아야 합니다.
- 검지 속이 두 칸이면 막대처럼 보입니다. 세 칸이 필요합니다.
- 검지 옆이 비어 있으면 다른 손가락으로 읽힙니다. 접힌 마디를 바짝 붙였습니다.
- 손끝은 양쪽을 한 칸씩 깎아 둥글렸고, 주먹 모서리도 굴렸습니다. 검지를 중간에 꺾었더니 누가 잡고 구부린 것처럼 보였고, 옆이 비어 있어서 다른 손가락으로 읽혔습니다. 주먹 모서리는 굴렸고 흰 손에 파란 소매를 달았습니다.

색은 `--edge-deep` 계열 남색 `#2E3A5C`, 흰색, 그늘 `#C9DCF5`, 소매 `#5D9EE4` 넷입니다.

바꾸실 때 조건입니다.

- **배경은 투명**이어야 합니다.
- **128px을 넘으면 브라우저가 무시합니다.** 32~48px 안쪽이 안전합니다.
- 기준점(`index.html`의 `--hand` 뒤 두 숫자)이 실제로 가리키는 지점과 맞아야 합니다. 손끝 픽셀의 좌표입니다.
