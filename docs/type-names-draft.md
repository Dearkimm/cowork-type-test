# 유형 이름 개편안 (논의용 초안)

아직 코드에 반영하지 않았습니다. 이 문서에서 단어를 정하면 그때 반영합니다.

## 짓는 규칙

- 이름 = 수식어 + 명사. 가장 치우친 축이 명사, 두 번째 축이 수식어입니다
- 명사는 탐험대 역할, 수식어는 [신중한] [완벽주의]처럼 짧은 성격어로 갑니다. 지금의 [미리 알아두는] 같은 동사구보다 이름답게 읽힙니다
- 같은 축의 낮음·높음 짝이 균형을 이뤄야 합니다. 한쪽만 착해 보이면 안 됩니다
- 한 축만 뚜렷하면 자기 축 수식어를 씁니다. [신중한 설계자] [완벽주의 대장장이]가 이 경우입니다

## 제안 단어

| 축 | 극 | 명사 (제안) | 수식어 (제안) | 아이템 | 명사 다른 후보 | 수식어 다른 후보 |
|---|---|---|---|---|---|---|
| 의견이 갈릴 때 | 먼저 듣는 | **참모** | **차분한** | 두루마리 | 책사 · 기록관 | 조용한 · 경청하는 |
|  | 먼저 말하는 | **선봉장** | **거침없는** | 깃발 | 돌격대장 · 기수 | 직진하는 · 돌직구 |
| 일과 사람 사이 | 사람을 먼저 보는 | **치유사** | **다정한** | 물약 | 집사 · 순례자 | 따뜻한 · 온화한 |
|  | 일을 먼저 보는 | **사냥꾼** | **냉철한** | 활 | 용병 · 추적자 | 담백한 · 결과지향 |
| 결과물을 낼 때 | 빠르게 내보내는 | **선발대** | **재빠른** | 횃불 | 전령 · 질주자 | 날쌘 · 속전속결 |
|  | 끝까지 다듬는 | **대장장이** | **완벽주의** | 망치 | 연금술사 · 세공사 | 집요한 · 장인정신의 |
| 일을 맡길 때 | 넘기고 기다리는 | **의뢰인** | **느긋한** | 의뢰장 | 길드마스터 · 후원자 | 통 큰 · 대범한 |
|  | 넘기고 확인하는 | **파수꾼** | **꼼꼼한** | 랜턴 | 감시탑 · 등대지기 | 섬세한 · 촘촘한 |
| 시작하기 전에 | 가서 맞추는 | **모험가** | **용감한** | 검 | 개척자 · 방랑자 | 몸이 먼저인 · 즉흥의 |
|  | 미리 알아두는 | **설계자** | **신중한** | 지도 | 전략가 · 지도제작자 | 준비된 · 계획적인 |

균형 짝: 차분한-거침없는 / 다정한-냉철한 / 재빠른-완벽주의 / 느긋한-꼼꼼한 / 용감한-신중한. 어느 쪽이든 칭찬으로도 놀림으로도 읽힙니다.

걸리는 지점을 미리 적어 둡니다.

- [치유사]는 착해 보이는 쪽으로 기웁니다. 짝인 [사냥꾼]이 멋있어서 버티는데, 아니다 싶으면 [집사]나 [순례자]가 후보입니다
- [의뢰인]은 퀘스트를 주고 기다리는 사람이라는 RPG 문법을 모르면 뜬금없습니다. [길드마스터]가 더 정확한데 다섯 글자라 깁니다
- [완벽주의]만 성격어가 아니라 명사형 수식어입니다. 제나 예시를 그대로 살렸습니다. [집요한]으로 바꾸면 결이 맞지만 어감이 셉니다
