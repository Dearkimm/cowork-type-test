- 두 축이 뚜렷한 경우: 80가지
- 한 축만 뚜렷한 경우: 10가지 (자기 축 수식어)
- 어느 축도 뚜렷하지 않은 경우: 1가지 (유연한 올라운더, 아이템 없음)
- **전체 91가지**
