# 유형 이름 전체 목록

결과 제목으로 나올 수 있는 이름 전부입니다. 가장 치우친 축이 명사를, 두 번째로 치우친 축이 수식어를 정합니다. 같은 두 축이라도 어느 쪽이 더 치우쳤는지에 따라 이름이 달라집니다.

명사는 탐험대 역할입니다. 명사마다 아이템이 하나씩 있어서 결과창 캐릭터가 들고 나옵니다.

- 두 축이 뚜렷한 경우: 80가지
- 한 축만 뚜렷한 경우: 10가지 (자기 축 수식어를 씁니다)
- 어느 축도 뚜렷하지 않은 경우: 1가지
- **전체 91가지**
